# 架构
Phaser 3.90 + TypeScript + Vite + React。首版默认 Canvas 渲染；`?renderer=webgl` 可用于比较 WebGL，当前不依赖 shader。选择成熟 Phaser 3 路线，依赖在 lockfile 固定，不自动切换大版本。
模拟 Simulation 拥有位置、实体、碰撞、伤害、冷却、随机数和会话状态；Phaser Scene 负责精灵/图形、相机、特效；React 负责 HUD、菜单和设置。
输入 → action map → Simulation.step → 视图同步 / HUD 快照。React 每 100ms 获取 HUD 状态，菜单变化立即更新；不持有逐帧敌人坐标。
Phaser 不使用第二套物理状态。固定 60Hz，帧累计上限 0.1 秒，暂停丢弃累积时间，避免标签页恢复追帧。
地板和五类敌人图形缓存成纹理；敌人视图按 ID 复用，数字文本使用池；弹体和效果设上限。随机数使用种子，调试可固定种子。实体有稳定数字 ID。优先设定敌人/弹体/效果上限，再按实测决定对象池和空间网格优化；不提前建设通用 ECS。
存档只保存版本化 JSON 的局外统计和设置，损坏回退默认。素材按 manifest key 加载，加载失败给出反馈和程序临时画面。

## v0.7.1 首屏适配
界面采用固定逻辑尺寸的整体构图，通过浏览器 visualViewport 的宽高计算统一缩放比例，并监听窗口和可视窗口 resize。桌面外框1124×780，包含64像素页头、1100×650竞技场、42像素页脚与边距；窄屏竖向外框524×914，提供完整五英雄菜单。留出16像素窗口余量，始终居中。
Phaser使用NONE缩放模式，保持1100×650模拟及渲染分辨率；CSS object-fit:contain保证地图比例，DOM菜单/HUD随外框同步缩放。避免Phaser FIT读取变换后的父尺寸后再次缩放。画布输入仍为键盘，技能由DOM按钮处理。取消旧窄屏min-height和相对定位弹窗，首屏显示所有菜单及弹窗，无页面或弹窗滚动。手机仅适配展示，尚未增加触屏移动。
验收覆盖1440×900、1366×768、1280×600、1024×768、800×500、390×844、375×667、844×390，切换窗口时检查可见元素边界和内容高度；覆盖菜单、战斗、暂停、升级、商店、胜负结算。

## v0.8 构筑玩法
默认运行 BuildSimulation（src/game/build-simulation.ts），继承基础移动/敌人/碰撞；旧Simulation只保留回归基线。内容表 build-content.ts 是武器、道具、角色偏向及波次的唯一运行数值源。
每个武器实例独立持有 uid/品质/冷却/朝向，弹体元数据记录命中过的敌人、剩余穿透次数与首次触发标记。二次伤害不再触发道具，防止递归。炮台独立发射，工程不受攻速加成。视图按武器 uid 复用与销毁，SVG武器在场景预加载。
波末收集未拾取材料并以80%支付金币，收获追加收入；经验升级全部在波间处理。商店四格独立锁定、刷新、购买状态，锁定跨波保留；满槽只允许直接购入可合成武器。局外构筑记录使用 rift-build-records-v1，旧音频设置沿用 rift-survivors-v1。
