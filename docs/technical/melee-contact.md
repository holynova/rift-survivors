# 近战接触与反馈 v0.9.1

原问题：BuildSimulation 按范围和角度瞬间结算伤害，Phaser 却只绘制角色周围固定武器与独立渐现特效。判定先于接触，表现像隔空击杀。

设计：起手占24%，有效接触24–68%，余下收招。匕首与矛伸出并回收，锤与镰从瞄准角−1.15到+1.15弧度挥过。锁定起手方向，敌人移动可躲开；每把武器独立攻击实例，单次命中集合防重复。匕首保留单体，矛贯穿，锤/镰扫击。保持原伤害、射程、攻速属性，判定改为真实刀身线段与敌人圆形碰撞，4ms子采样避免穿透漏判。

`src/game/melee.ts` 提供共享姿态/线段接触；模拟和Phaser渲染读取同一姿态。只冻结命中的武器25ms（锤55ms），其他武器/玩家/波次时间正常运行，密集敌群不累积全局卡顿。火花绘制在最近接触点，接触后才播放刀/矛/锤/镰的肉体与金属层；挥空只有挥动声。重锤轻震屏55ms，减少动态模式关闭震屏和拖尾，核心武器轨迹保留。

参考方向：Brotato官方介绍及展示的六武器竞技场 https://store.steampowered.com/app/1942280/Brotato/ 。刺击/挥扫分类参考社区武器资料 https://brotato.wiki.spellsandguns.com/Weapons 。以上用于设计方向；未宣称复现原作隐藏数值或源码。

验证：6项近战规则回归（延迟接触、矛直线贯穿、躲开起手方向、前方扫击且不重复、局部停顿不阻塞其他武器、贴身目标无盲区）；浏览器逐一检查四种近战实体与共享判定位置一致，暂停不漂移。截图 `evidence/melee-*.png`。

验收结果：58项规则通过；原8项浏览器回归与新增四近战姿态/暂停检查通过，生产构建通过。近战截图为暂停模拟并隐藏暂停遮罩，方便审查实体姿态，不作为实时命中视频。
