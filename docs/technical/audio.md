# v0.7 音频

本版音效采用25段经过筛选、裁切、滤波、淡入淡出和峰值匹配的Kenney CC0素材。来源：
- https://kenney.nl/assets/impact-sounds
- https://kenney.nl/assets/rpg-audio
- https://kenney.nl/assets/sci-fi-sounds

三包原始ZIP、提取素材和项目选择清单保存在art/audio-source/v7。授权声明一并保存在下载包中和public/assets/audio/v7/LICENSE.txt；不依赖外部音频服务器。scripts/prepare-audio-v7.py 使用ffmpeg处理25段单声道44100Hz PCM WAV，合计993130字节；输出清单src/game/audio-bank.ts与原素材selection.json可对应。

枪手：短促爆破与低频冲击；工程师/炮台：较轻机械射击和金属动作。骑士：低速挥刃与布料破风；猎手：短而快的双刃质感。术士：碎玻璃/冰裂与轻能量纹理。主动/终极技能分角色分层，爆发低频冲击居中；金属护甲命中与普通命中区别处理，领主落地有空间位置反馈。购买改为金币与机关声，警告/胜负采用低频和金属铃声。连续攻击、命中与击杀不再使用振荡器扫频作为主体。

混音：素材高通55Hz、按用途低通2400–6500Hz，音效总线3800Hz高频架降低4dB。波形实际尾部淡出，避免截断点击。轮换多个变体并轻微变速，原地同一动作不连续重复同一素材。按位置轻微立体声分配；普通命中限频160ms、击杀220ms、炮台160ms、攻击105ms，低音量保留关键信息。受伤与终极技能平滑压低背景音乐到60%再恢复，避免强烈抽吸。

运行：首次点击开始后解锁AudioContext，四路并发加载/解码并在就绪后进入战斗。加载按钮有等待反馈；失败素材记录到开发诊断，不能阻止整场游戏。重复开局复用已解码音频。实时最多96声源，其中采样最多48；结束释放source/gain/pan节点。音乐、音效开关和音量继续分别保存，旧存档兼容。暂停/失焦停止音乐，音效保留短暂自然尾音。

背景音乐继续使用原创程序编曲：Am/F/C/G动机、和弦、低音、旋律、鼓组，前期108、中期120、最终战132BPM，低生命和怪潮强化节奏。背景音乐的tone/noise与采样音效分开处理。

验证：node scripts/audio-audition-v7.mjs 使用同一播放实现离线渲染22秒旧版/新版对照；旧版实现归档audio-before.ts，离线放宽未来节点排程预算。evidence/audio-v7-before.wav、audio-v7-after.wav和audio-v7-ab.json记录素材解码、峰值、RMS和节点回收。新版峰值约0.306、RMS0.0314，无削波；这些指标不替代耳机与音箱的主观音色反馈。音效触发与素材路径测试、浏览器播放/静音/恢复及正式公网验收另见试玩日志。


## v0.9 预渲染配乐
新增四段原创16小节AAC立体声循环，取代正常播放路径的逐音符振荡器。前期1–3、中期4–7、后期8–11、领主12，650ms交叉淡化。加载与解码成功4轨，音效仍25个Kenney样本；音量、暂停和静音回归通过。详细音色、谱面、资源路径及验收见 [资源记录](../art/resources-v09.md)。资源图鉴提供直接试听。
