# 战斗规则
模拟固定步长 1/60 秒，位移使用秒为单位速度。地图 1100×650，玩家与敌人碰撞圆独立于图像。
伤害=max(1,round(基础伤害×倍率×暴击倍率-护甲))，暴击倍率 2。玩家命中后 0.6 秒保护，技能无敌优先于受击。
精力不足时暂停骑士自动攻击，精力继续回复。敌人受伤后击退；剑击为面向目标的扇区。
敌人：慢速近战、快速追击、保持距离的远程射手。精英为有预警的冲击怪。Boss 周期锁定玩家地面圆形预警并砸击，随后环形弹幕，半血后加快技能频率。
预警在爆发前固定落点；不跟随玩家。Boss 与精英免疫瞬间清屏，但正常承受技能伤害。
拾取、攻击、伤害、AI、技能、波次均由模拟层管理，视图只能消费结果。
