# v0.8 多武器构筑竞技场

目标：战斗以走位为主，波间商店决定构筑。替换固定主动技能，不在数值卡牌上继续叠加新技能。

- 三角色：时间枪手（远程收益高、近战低）、灰烬骑士（近战与护甲高、远程低）、机巧召唤师（工程收益高、普通武器低）。开局选择适配的初始武器。
- 12种武器，6个槽位，独立冷却和目标选择；4级品质，同种同级合成。武器有近战、远程、元素、工程缩放以及枪械、刃器、重装、元素、装置标签。
- 30件道具，至少8件机制道具：暴击冰区、击杀碎片爆炸、撞墙冲击、过量治疗护盾、站定装置增强、穿透强化、击中弹射、冰冻破碎。其余属性道具包含明确收益/代价及经济投入。
- 12波，33–66秒渐长；4/8/10波精英、12波Boss。升级在波间结算，连续等级依次选择，然后进入4格商店。
- 材料拾取同时提供经验与购物货币；未拾取材料在波末折算部分收入。收获在波末支付。初期保证武器供给；后期品质由波次和幸运共同影响。
- 商店：买、递增成本刷新、锁定跨刷新/跨波保留、出售武器、合成；满槽购买只能合成匹配武器或先卖。合成不收费，卖出可返一部分购置价值。
- 有限槽位、合成减少武器数量、类型属性投入、经济与生存取舍构成决策。拒绝伤害倍增无限触发；机制效果不能递归触发自身。
- HUD展示武器、类别/标签收益及属性；商店展示实际缩放后伤害和攻击间隔。维持窗口首屏适配，手机仅展示，战斗使用键鼠。

实施顺序：规则与内容 → 多武器战斗/经济 → 商店与HUD → 确定性组合和经济测试 → 浏览器实际输入与波间流程/首屏/音频 → 生产构建与手动发布。保留旧模拟作为回归基线，浏览器默认使用新构筑模拟。

验收重点：六武器各自开火、合成/满槽边界、锁定和消耗一致、不同属性改变武器收益、机制可触发且不无限递归、12波胜负/升级/购物闭环；自动机器人只是规则冒烟，不作为真人胜率证明。
