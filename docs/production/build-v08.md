# v0.8 本地开发与验收

日期：2026-10-03。状态：本地可玩开发版；本次未更新公网，公网保持此前v0.7.2。

## 已实现
- 三角色偏向和三种适配初始武器选择，六槽自动攻击；12种武器具有独立冷却、范围、目标、类型属性、四级品质。
- 30件道具，其中8件改变行为。暴击冰区、击杀碎片、撞墙、溢出护盾、阵地强化、贯穿、弹射、碎冰均有确定性测试。二次伤害不递归；霰弹每轮仅一次弹射。
- 12波33–66秒，4/8/10波精英、12波领主。波间升级、四商品商店、锁定跨波、递增刷新成本、买卖合成、满槽购入匹配武器直接合成。
- 拾取材料提供经验和金币，剩余材料80%金币结算，收获追加收入，波末恢复12%生命。合成不花钱但失去一份攻击频率和家族数量；出售至少保留一把武器。
- 菜单、战斗、升级、商店、暂停、胜负首屏适配。独立音量设置保留，构筑成绩独立存档，开发接口仅开发构建开放。

## 验证与证据
Vitest 51项：原模拟30项回归、新规则20项与整局机器人1项。Playwright 6项串行回归：动画、音频/设置、角色开局、真实键盘移动/暂停/购物/Boss流程、损坏存档、8种视窗覆盖全部状态。视窗压力包含六武器和30种道具同时显示。

- evidence/v08-build-bots.json：三个角色各两个种子，正常金币、采购、合成与走位，未修改血量或攻击数值。枪手一胜一第12波落败，近战第5/10波落败，工程一胜一第12波落败。
- evidence/v08-performance.json：六武器、300敌人、600弹体合成压力；测试机无头Chromium Canvas，平均60.03FPS，采样最大模拟更新8.6ms（不是通用设备性能承诺）。
- evidence/v08-menu-desktop.png、v08-menu-portrait.png、v08-shop-desktop-full.png、v08-shop-portrait-full.png、v08-battle.png：代表状态截图。
- npm run build：类型检查及生产打包；dist/release.json覆盖115个文件。

机器人仅验证流程、经济和边界，并不证明玩家通关率、难度平衡或好玩程度。近战需要更贴近敌群，后续应针对真人试玩调节击退与生存收益。手机目前仅适配展示，尚未增加触屏操作。
