# 2026-09-30 · 首个可玩版本验收

## 状态
M1 文档基线、M2 战斗原型、M3 八波短局已实现。M4 自动规则与浏览器流程验证完成；人工完整对局平衡、长时间内存与跨浏览器验收仍未完成。当前是可玩原型，不是完成全部六英雄内容的正式发行版。

## 验证结果
- TypeScript 类型检查通过，生产构建通过。
- Vitest 13 项规则测试通过；Playwright 2 项流程/响应式用例通过。
- 浏览器实际检查两名英雄、移动、三种技能输入、暂停、升级、商店、Boss 预警、胜利、失败、重开。截图见 ../../evidence。
- 正式构建首载、技能和暂停通过，运行错误为零、资源失败为零、无外部网络资源请求；开发调试接口已移除。
- 手机 375px 菜单无横向溢出，标题断行已修复；触控战斗未实现。
- 失焦自动暂停已用事件触发验证，移动实际输入 0.7 秒位移 147 像素，与枪手 210px/s 相符。

## 性能
设备 Apple M1，darwin arm64；无头 Chromium 153.0.8010.12；1920×1080。
默认 Canvas。正常短时输入试玩末次约 60.7 FPS。合成压力场景持续维持 300 敌人与 600 弹体，约 3 秒采样平均 58.2 FPS，模拟更新平均 0.12ms、最大 2.50ms。
压力环境关闭玩家受伤并禁用自动攻击，以维持固定实体数量，这些仅存在调试夹具，不能作为正常通关证据。目标稳定 60FPS 尚未得到长时间证明。原始样本见 evidence/browser-performance-canvas.json。

## 已修复
测试连接到其他项目的 5173 端口，改用本项目 5188；Boss 边缘生成被裁切，改为按半径留边；缓存地板与敌人纹理；移除外部字体请求；关闭平滑 delta 防止低帧率下游戏时间变慢；区分规则和浏览器测试目录；升级测试依赖消除已知审计问题。

## 美术与剩余限制
英雄使用生成并归一化的静态种子帧，移动为程序轻微摆动；待机/移动动画条尚未量产。敌人、Boss、地板和音效是程序原型资源。尚未运行 Safari/Firefox 完整验收、完整人工通关或长时间内存测试。六英雄/二十波/进化/第二地图属于后续路线。

## 复现
npm test；npm run test:browser；npm run test:balance。
先启动 5188 开发服务再执行 npm run test:perf。先 npm run build 并启动 npm run preview（5189）再执行 npm run test:release。
